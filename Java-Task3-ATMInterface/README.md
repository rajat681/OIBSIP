# ATM Interface - Java Project

## Project Description
This project is a simple ATM Interface developed using Java.
It allows users to log in and perform basic banking operations.

## Features
- User login with User ID and PIN
- Limited login attempts
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Exit the ATM system

## Technologies Used
- Java
- VS Code
- Object-Oriented Programming (OOP)

## How to Run
1. Open the project in VS Code.
2. Compile the Java files.
3. Run Main.java.
4. Enter the User ID and PIN.
5. Select an option from the ATM menu.
