Online Examination System

Project Overview

This project is a Java-based Online Examination System developed using Java Swing.

Features

* Student login system
* Student profile update
* Multiple-choice questions (MCQs)
* 30-minute examination timer
* Next and Previous question navigation
* Automatic submission when time ends
* Manual exam submission
* Result with score and performance details
* Logout option

Technologies Used

* Java
* Java Swing
* AWT

How to Run

1. Install Java JDK.
2. Open the project folder in a terminal.
3. Compile the program:
    javac Main.java
4. Run the program:
    java Main
